# 타깃18(A·B 공통 불만→환불) 초반 고객 arousal 점검

가설 확인용 진단이며 층화 실험이 아니다. API 호출 0, 전부 로컬 파일. gold_actual은 그룹을 나누는 데만 쓰였고 arousal 계산에는 쓰이지 않았다.

## 0. 그룹 정의

- 타깃18 = gold=불만제기 & A예측=환불요청 & B예측=환불요청: **18건**
  (A 단독 19건, B 단독 19건 -> 교집합 18건. 당초 예상 19건이 아니라 18건)
- (ㄱ) 맞춘불만 = gold=불만제기 & (A 또는 B가 불만제기): **10건**
- (ㄴ) 전체불만 = gold=불만제기: **50건**
- (ㄷ) 비불만전체 = gold!=불만제기: **200건**

타깃18과 맞춘불만은 겹치지 않는다(예측이 서로 배타적). 전체불만은 타깃18·맞춘불만을 포함하는 상위 집합, 비불만전체는 분리 집합이다.

## 1. 코퍼스 baseline

원천: `stage2_acoustic_features.parquet` 전체 발화 135,340건 (batch1 stage2 pool). 성별·화자·유효성은 `d04_dialog_index.parquet`에서 병합.

- 화자 필터: `speaker_type`이 '고객'으로 시작 (고객1/2/3). 135,340 -> **85,196건** (id 미사용, type 필드만)
- truncated 제외: `r_gold_valid_flag != True` **0건** 제외 (85,196 -> 85,196건). stage2 pool이 이미 valid만 담고 있어 0건.

추출기·파라미터 (`stage2b_acoustic_extract.py`, 기존 추출물 재사용 / WAV 재추출 없음):

- **F0**: `parselmouth` (Praat) `Sound.to_pitch(pitch_floor=75.0, pitch_ceiling=500.0)`, `frequency > 0`인 **유성 프레임만** 사용해 평균 -> 발화별 `f0_mean`. 무음/무성 프레임 제외.
- **RMS**: `librosa.feature.rms(y=y)` (기본 frame_length=2048, hop_length=512), `librosa.load(sr=None)`으로 원본 샘플레이트 유지 -> 발화별 `e_mean_amp`(linear RMS 평균).
- **에너지 지표 선택**: `e_mean_db`는 `amplitude_to_db(rms, ref=np.max)`로 ref가 발화 자신의 피크라 발화 간 절대 성량 비교에 부적합(사실상 dynamic range). 따라서 `z_energy`는 **`e_mean_amp`(raw linear RMS)** 기준이며, `e_mean_db` 기반 값은 `z_energy_db`로 참고 저장만 한다.
- **baseline 입도**: 프레임 단위 풀링이 아니라 **발화별 집계값의 분포**다(프레임 raw는 저장돼 있지 않고, WAV 재추출은 외장하드 미연결로 불가). 프레임 풀링 대비 std가 작아 z의 절대 크기가 달라진다.
- **표본 포함 범위**: 이번 250건도 baseline에 포함돼 있다(전역 통계 85,196건 대비 비중이 작아 영향 미미).

## 2. 콜별 초반 arousal

대상 발화 = 프롬프트가 실제로 본 것과 동일한 창(`stage2_windows_nl_v2`, window_n=5, window_version=customer_only) = 초반 5발화 중 고객 발화. 총 1,119발화 / 250콜.

- 콜 단위 집계: 해당 발화들의 `f0_mean` / `e_mean_amp` / `e_mean_db` **단순 평균** (발화 길이 가중 아님).
- 성별은 콜 내 고객 발화의 최빈값 사용.
- z-score는 **해당 콜 성별의 baseline** 기준. `arousal = (z_pitch + z_energy) / 2`.
- 초반 창에서 acoustic 결측 발화: **0건**.
- 프레임 수는 저장돼 있지 않아 `n_utt_초반`(발화 수)과 `dur_초반_sec`(구간 길이 합)으로 대체 기록한다.

- 250건 중 arousal 산출 실패: **0건** (분포 계산에서 제외, 삭제 아님)
