# 11. 각성도(arousal) 라벨링 전 타당성 스크리닝

**질문**: 사람 청취 라벨링에 공수를 들이기 전에, 음향 통계만으로 각성도가 새 타깃으로 쓸 만한지 먼저 판정할 수 있는가?

기존 타깃(불만제기)은 어휘로도 상당 부분 풀려 음성 기여가 작았고 라벨도 2.5%로 희귀했다. 대안으로 검토 중인 각성도(흥분↔평온) 역시 격앙 통화가 적어 또 불균형에 빠질 위험이 있어, **라벨링 착수 전** (1) 격앙 통화 비율, (2) 고/저각성의 음향 분리도, (3) 8kHz에서의 신호 생존을 먼저 본다.

**라벨은 만들지 않았다.** proxy 점수는 정답이 아니며, 골드 라벨은 이후 사람이 음성만 듣고(전사 보지 않고) 만든다.

## 스크립트

| 스크립트 | 역할 |
|---|---|
| `scripts/arousal_screen.py` | 콜 단위 음향 요약통계 → arousal proxy 4종 → 분포·임계값·군간비교·교란점검·청취표본 |

발화 선택은 §3.1 음향 파이프라인(`stage2a_window_pool.py` / `stage2b_acoustic_extract.py`)과 동일 규칙을 재사용한다: 고객 발화만, `r_gold_valid_flag==True`, `dialog_idx` 오름차순 앞 5개 고객 발화. WAV 재추출 없이 기존 추출물만 읽는다(외장하드 불필요).

## proxy 점수

전부 해석 가능한 등가중 선형 결합이며 학습 모델이 아니다. 각 항은 **같은 성별 콜 분포 안에서의 z-점수**다.

| 점수 | 구성 |
|---|---|
| `P1_core` **(기본)** | mean(z_f0, z_energy, z_energy_var) |
| `P2_prosody` | + z_f0_var, z_rate |
| `P3_silence` | + −z_silence |
| `P4_gain_robust` | mean(z_f0, z_energy_cv, z_dyn, z_rate) — 회선 게인 비의존 |

`P4`를 따로 둔 이유: 8kHz 전화망의 raw RMS는 회선·단말 게인에 비례해서 "목소리가 크다"와 "녹음 레벨이 높다"가 분리되지 않는다. `P1` vs `P4` 순위상관이 이번 스크리닝의 핵심 타당성 점검이다.

## 실행 모드

| 모드 | 소스 | 비고 |
|---|---|---|
| FULL | `outputs/d04_dialog_index.parquet` + `outputs/stage2_acoustic_features.parquet` | 고객 전용 / 성별 실측 / 오디오 경로 포함 |
| PROXY | `results/05_gate/train_10k_pool5_labeled.parquet` | `outputs/` 없는 환경의 대체. **현재 수록본이 이 모드 결과** |

수록된 결과는 PROXY 모드다. 이 모드의 pool5는 "앞 5발화(상담사 포함) ∪ 앞 5개 고객 발화"라 **상담사 발화가 섞여 있고**(콜당 평균 6.78발화), 성별이 F0 기반 추정이며, 오디오 경로가 없다. 상담사 발화는 각성도 신호를 희석시키므로 고객 전용으로 다시 뽑으면 분리도는 **좋아지는 방향**으로 움직일 가능성이 크다. 최종 판정은 FULL 모드 재실행 결과로 한다.

## 결론 (PROXY 모드 10,000콜 기준)

판정은 사용자가 한다. 아래는 판정 기준에 대응하는 숫자다.

| 물음 | 숫자 | 읽기 |
|---|---|---|
| 고각성 비율 (z ≥ +1σ) | 15.06% (정규분포 기대 15.87%, **0.95×**) | 정규분포보다 **얇다** |
| 분포 비대칭도 (skewness) | +0.10 | 사실상 대칭 단봉 |
| `P1_core` vs `P4_gain_robust` ρ | **0.425** | 게인 항을 빼면 순위가 절반 이상 바뀜 |
| `z_f0` × `z_energy` ρ | **+0.20** | 피치와 성량이 따로 논다 |
| held-out `z_rate` (Cohen's d) | **−0.25** | 고각성군이 오히려 **느리게** 말함 |
| held-out `z_dyn` (Cohen's d) | **−0.18** | 방향 반대 |
| 수집 배치 교란 η²(`P1_core`) | 0.0060 | 배치 수준 교란은 **기각** |
| 품질 플래그 콜 비율 | 0.58% | 8kHz 추출 자체는 안정적 |

**세 가지가 부정 방향으로 모인다.**

1. **분포에 격앙 덩어리가 없다.** 점수는 대칭 단봉이고 상단 꼬리가 정규분포보다 오히려 얇다(0.95×). "격앙 통화 몇 %"라는 물음이 성립하려면 상단에 별도 덩어리가 있어야 하는데 없다. 상위 15%를 자르면 정의상 15%일 뿐, 어디를 끊어도 임의적이다.
2. **단일 각성도 축이 보이지 않는다.** 각성도가 실재하는 잠재 차원이면 그것이 구동하는 지표들끼리 상관이 있어야 하는데, 피치×성량이 +0.20에 그친다. `P1_core` 세 항의 평균 쌍별 상관은 +0.24다.
3. **held-out 지표가 반대로 간다.** 각성도가 오르면 말이 빨라져야 하는데 고각성군이 오히려 느리다(d=−0.25). 방향이 맞는 `z_silence`(+0.71)·`z_energy_cv`(+0.70)는 성량과 기계적으로 얽혀 있어(`z_silence`×`z_dyn`=−0.74) 독립 증거로 세기 어렵다.

즉 현재 proxy 상위군은 "각성된 콜"보다 **"크게 녹음된 콜"**에 가깝다. 배치 수준 게인 교란은 기각됐지만(η²<0.02) 콜 단위 회선 게인은 남아 있다.

**다음 검정** — 라벨링 공수를 넣기 전에 이것부터: 같은 콜의 **상담사 발화 성량**과 고객 성량의 상관. 강하면 점수는 회선 게인이고, 약하면 고객 성량은 화자 고유 특성이라 각성도 해석이 살아난다. FULL 모드 데이터로 바로 계산된다.

**참고(약한 긍정 신호 하나)**: 기존 `gold_actual` 기준 불만제기 비율이 고각성 상위 10%에서 2.9%, 저각성 하위 10%에서 1.7%로 방향은 맞다(1.7× enrichment). 다만 절대량이 작아 결정적이지 않다.
